Review of material¶

This homework is about linear and nonlinear regression. From the lecture we remeber that, if

$$ y_i = {\bf w}^T {\bf x}_i + b + {\epsilon}_i ~~~~ {\text for} ~~ i=1, \cdots, N $$

where, $b$ is the bias, and $\epsilon_i \sim N(0, \sigma^2)$. We also saw that with a change of variavle $$ {\bf x} \leftarrow \begin{bmatrix} 1 \\ {\bf x} \\ \end{bmatrix} $$ $$ {\bf w} \leftarrow \begin{bmatrix} b \\ {\bf w} \end{bmatrix} $$ we can simplify the above equation to $$ y_i = {\bf w}^T {\bf x}_i + {\epsilon}_i ~~~~ {\text for} ~~ i=1, \cdots, N $$ For the training set $D = \{ ( {\bf x}_1, y_1), ( {\bf x}_2, y_2), \cdots, ( {\bf x}_N, y_N) \}$ we showed that the likelihood function can be written as $$ l({\bf w}) = 1/N \sum_{i=1}^N ({\bf w}^T{\bf x}_i - y_i)^2 $$ and the maximum likelihood estimate of ${\bf w}$ given set $D$ can be written as $$ \hat{\bf w}_{ML} = \underset{\bf w}{argmin} ~ l({\bf w}) $$ therefore to find $\hat{\bf w}_{ML}$, we need to take the derivative of the above equation

$$ \begin{align} \nabla l({\bf w}) &= \nabla l(\left.w_{1}, w_{2}, \ldots, w_{d+1}\right) \\ \\ &=\left[\begin{array}{c} \dfrac{\partial l}{\partial w_1}(\left.w_{1}, w_{2}, \ldots, w_{d+1}\right)\\ \dfrac{\partial l}{\partial w_2}(\left.w_{1}, w_{2}, \ldots, w_{d+1}\right) \\ \vdots \\ \dfrac{\partial l}{\partial w_{d+1}}(\left.w_{1}, x_{2}, \ldots, w_{d+1}\right) \end{array}\right] \\ \\ & = 1/N \sum_{i=1}^N {\bf x}_i ({\bf x}_i^T {\bf w}- y_i)\\ \end{align} $$

where $\nabla l({\bf w})$ is the gradient of likelihood function $l({\bf w})$. In future we use the gradient in a gradient descent algorithm to find the minimum of the function. Here we set $\nabla l({\bf w}) = 0$ and solve for ${\bf w}$. As we saw in the class the solution can be written as follows

$$ \hat{\bf w}_{ML} = ({\bf X} {\bf X}^T)^{-1}{\bf X}{\bf y}^T $$

where $$ {\bf X} = [{\bf x}_1, {\bf x}_2, \cdots, {\bf x}_N] $$ and $$ {\bf y} = [y_1, y_2, \cdots, y_N] $$

Problem Description¶

The goal of this problem is to extend the linear regression and find a higher order polynomial fit for the given data. In the following we first describe the problem and then show an analytical solution. Then we generate the training data and the we state the problem.

Now we want to apply the linear estimation for nonlinear cases¶

Assume that the best fit for the training set $D = \{ ( { x}_1, y_1), ( { x}_2, y_2), \cdots, ( { x}_N, y_N) \}$ is the polynomial

$$ y_ i = a_0 + a_1 x_i + a_2 x_i^2 + \cdots + a_p x_i^p $$

we can define $$ {\bf x} = \begin{bmatrix} {1} \\ x \\ x^2 \\ \vdots \\ x^p \\ \end{bmatrix} $$ Therefore, for every value of $x_i$ in our training data set we can generate a vector

$$ {\bf x}_i = \begin{bmatrix} {1} \\ x_i \\ x_i^2 \\ \vdots \\ x_i^p \\ \end{bmatrix} $$

We can still use

$$ {\bf X} = [{\bf x}_1, {\bf x}_2, \cdots, {\bf x}_N] $$

and

$$ {\bf y} = [y_1, y_2, \cdots, y_N] $$

Then your solution should be exactly to the one we expressed above, i.e. we get

$$ \hat{\bf w} = ({\bf X} {\bf X}^T)^{-1}{\bf X}{\bf y}^T $$

Use polynomial dregrees $p=2, 3, 4$, and $10$ to find the best fit for the generated data. Follow the procedure shown for the linear case to calculate the error for each case for the training data and for the test data.

import numpy as np
import matplotlib.pyplot as plt

# Seed for reproducibility
np.random.seed(123)

# Generate data
N = 100
b = 3.2
a3 = -0.2
a2 = 0.1
a1 = -1
x = np.random.normal(0, 3, N)
y = a3 * np.power(x, 3) + a2 * np.power(x, 2) + a1 * x + b + np.random.normal(0, 10, N)

# Split data into training and testing
N_tr = int(N * 0.8)
N_tst = N - N_tr
x_tr = x[:N_tr]
y_tr = y[:N_tr]
x_tst = x[N_tr:]
y_tst = y[N_tr:]

# Function to fit a polynomial model and calculate errors
def fit_and_evaluate(x_tr, y_tr, x_tst, y_tst, degree, ax):
    X_tr = np.vander(x_tr, degree + 1, increasing=True)
    X_tst = np.vander(x_tst, degree + 1, increasing=True)
    w = np.linalg.inv(X_tr.T @ X_tr) @ X_tr.T @ y_tr
    y_tr_pred = X_tr @ w
    y_tst_pred = X_tst @ w
    train_error = np.mean((y_tr_pred - y_tr) ** 2)
    test_error = np.mean((y_tst_pred - y_tst) ** 2)

    # Plotting results
    ax.scatter(x_tr, y_tr, color='red', label='Training data')
    ax.scatter(x_tst, y_tst, color='blue', label='Test data')
    x_line = np.linspace(min(x), max(x), 1000)
    y_line = np.vander(x_line, degree + 1, increasing=True) @ w
    ax.plot(x_line, y_line, color='green', label=f'Fit degree {degree}')
    ax.legend()
    ax.set_title(f'Degree {degree} Fit\nTrain Error: {train_error:.2f}, Test Error: {test_error:.2f}')
    ax.set_xlabel('x')
    ax.set_ylabel('y')
    return train_error, test_error

# Plotting
fig, axes = plt.subplots(1, 4, figsize=(24, 6), sharey=True)
degrees = [2, 3, 4, 10]
errors = {}
for i, degree in enumerate(degrees):
    errors[degree] = fit_and_evaluate(x_tr, y_tr, x_tst, y_tst, degree, axes[i])

plt.tight_layout()
plt.show()

Problem 2 [1 point]¶

Please, compare the four results and explain which $p$ degree would be best to use. Justify your answer.

We assessed polynomial regression models of degrees 2, 3, 4, and 10, focusing on their training and testing errors to identify the best polynomial degree:

  • Degree 2: High errors indicate the model is too simple.
  • Degree 3: Both training and testing errors are low, showing the model is complex enough to capture the data's patterns without overfitting.
  • Degree 4: This model has a lower training error than degree 3 but a higher testing error, suggesting it might be starting to overfit.
  • Degree 10: This model fits the training data very well but performs poorly on new, unseen data, which is a classic sign of overfitting.

Recommendation¶

It is recommended to use the polynomial of degree 3. It is a good balance between being accurate and general, captures the data patterns well, and is less likely to overfit, making it suitable for predicting new data.

Conclusion¶

The degree 3 model is effective because it fits the data well and remains reliable when applied to new data, as shown by its performance.
